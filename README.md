# CoffeeUMS English local replica

The local site includes the original CoffeeUMS wordmark in `assets/` and a scroll-driven LiDAR-style campus canvas. Each platform stage focuses the visualisation and labels on a campus area.

Open `index.html` directly in a modern browser, or run a local static server from this folder:

```powershell
python -m http.server 8080
```

Then open `http://localhost:8080`.
